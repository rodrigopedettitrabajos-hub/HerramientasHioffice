✎Nombres de columnas

El JSON de HiOffice no trae el nombre de los atributos estándar. Escribe aquí cómo se llama cada uno: el nombre queda guardado por ID y se usa en todos los JSON que abras. Si el bloque tiene un subtítulo propio, en pantalla se ve el subtítulo.

Los nombres se guardan en este navegador. Para no perderlos, o para pasarlos a otra persona u otro equipo, usa “Descargar el programa con los nombres incluidos”: te baja una copia del conversor que ya los trae dentro.

✓Validar un JSON de dashboard o exportación

Revisa sin conexión que el JSON esté bien armado antes de subirlo a HiOffice: referencias entre bloques, columnas, fórmulas y filtros, y que la acción de exportación esté enlazada a un perfil CSV/PDF válido. No garantiza que HiOffice lo acepte (para eso está la pestaña Bridge), pero detecta los errores que harían fallar la carga.

Cómo usar el ayudante local



Si al conectar aparece que el navegador bloqueó la llamada, el servidor de HiOffice no acepta llamadas directas desde una página. El ayudante hace de intermediario en tu propio equipo:


  1. Abre Herramientas_HiOffice.exe (en la misma carpeta que esta página).
  2. Se abrirá esta herramienta en http://127.0.0.1:8765 y arriba verás “Conectado mediante el ayudante local”.


El programa sólo escucha en tu equipo y sólo reenvía llamadas a servidores de HiOffice (icg.eu / hiopos.com).
